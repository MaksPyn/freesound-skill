# Contributing

Thank you for helping improve Freesound Agent Skill.

## Before opening a pull request

1. Fork the repository and create a focused branch from `main`.
2. Keep changes small and follow the existing dependency-free Node.js style.
3. Add or update tests when behavior changes.
4. Run the test suite:

   ```bash
   node --test tests/freesound.test.js
   ```

5. Update the documentation when commands, options, or behavior change.

## Pull requests

Explain what changed, why it changed, and how you verified it. Do not include API keys, OAuth tokens, downloaded audio, or other private data in commits, logs, issues, or pull requests.

By contributing, you agree that your contributions are licensed under the [MIT License](LICENSE).

## Bug reports and feature requests

Use GitHub Issues for reproducible bugs and focused feature requests. For vulnerabilities, follow the private reporting process in the [security policy](.github/SECURITY.md) instead of opening a public issue.
